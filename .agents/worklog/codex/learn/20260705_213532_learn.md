# Learnings
Presidio built-in `EmailRecognizer`, `PhoneRecognizer`, `CreditCardRecognizer`, `IpRecognizer`, and `UrlRecognizer` can be called directly without `AnalyzerEngine` or NLP model downloads. `PhoneRecognizer` accepts `nlp_artifacts=None` at runtime, but mypy needs that boundary cast because the base recognizer type is stricter.

# Plan Updates
For offline deterministic PII work, prefer direct built-in recognizer invocation plus explicit true-positive/false-positive tests before considering NLP NER.
