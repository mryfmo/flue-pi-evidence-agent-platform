# Learnings
Container validation can run without `.git` because `.dockerignore` excludes it. OPA bundle revisions therefore need a deterministic fallback chain: explicit env revision, git short SHA when available, then a content hash over sorted policy files.

# Plan Updates
For bundle-producing scripts, test both repo and no-git execution paths before relying on git-derived metadata.
