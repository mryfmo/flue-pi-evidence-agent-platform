# Date
2026-07-05

# Learnings
- SQLGlot policy checks are easier to maintain when split into whole-query checks and per-SELECT projection checks.
- Scanning `expressions.Column` over the whole expression denied PII across WHERE, GROUP BY, HAVING, ORDER BY, CTEs, and nested subqueries in one validated rule.
- For aggregate-only metrics, allow plain `Column` projections only when the column appears in the same SELECT's GROUP BY; allow only explicit aggregate expression classes for aggregate projections.

# Plan Updates
- Future SQL-guard plans should test policy by SQL shape, not exact SQL string.
- Tests should include at least one accepted grouped aggregate, one non-grouped bare projection rejection, one star rejection, one unknown table rejection, and one nested PII rejection.
