# P8-T06: 監査突合 CLI(task_id 一括トレース)

- Author: orchestrator-fable5, 2026-07-08
- Basis: `.orchestration/analysis/litellm_claude_code_integration_review.md` 問題 17(MVP-AC-009 相当)。前提: P8-T03(監査イベントの task_id/agent_profile)、P8-T04(events.jsonl / leases.json)accepted。

## 1. Objective

監査担当が 1 つの task_id から全証跡へ辿れることを機械化する。分散した記録(orchestration 台帳、基盤 JSONL 監査ログ、テレメトリ)を task_id で突合し、一括出力する決定論 CLI を提供する。

## 2. Deliverables

1. **`scripts/audit-trace.mjs`(新規)** — `node scripts/audit-trace.mjs <task_id> [--json|--md]`:
   - 収集元: (a) `.orchestration/tasks/<task_id>.md`(委譲仕様)、(b) `.orchestration/orchestrator/events.jsonl`(delegate/accept イベント)、(c) `.orchestration/reports|validation|sandboxes|acceptance/<task_id>*`(存在+パス+status 抽出)、(d) `artifacts/audit/*.jsonl` の task_id 一致イベント(llm_gateway_call 等)、(e) `artifacts/telemetry/traces.jsonl` の gateway.task_id 一致 span(存在すれば)、(f) `.orchestration/orchestrator/leases.json` の該当リース。
   - 出力: セクション分け(delegation / policy decisions / sandbox / llm events / validation / acceptance / leases)の Markdown(既定)または JSON。**見つからないセクションは `missing` と明示**(空を成功に見せない)。
   - 生プロンプト・秘密情報を出力しない(監査ログ自体がダイジェスト中心である前提を保つ。もし本文フィールドを検出したらダイジェストのみ表示)。
   - exit code: task_id の記録がゼロ件なら exit 1。
2. **`package.json` に script 追加**: `"audit:trace": "node scripts/audit-trace.mjs"`。
3. **テスト** — `tests/unit/audit_trace.test.*`: フィクスチャ(一時ディレクトリに各台帳の最小サンプル)で: 全セクション揃いの正常系、部分欠落(missing 表示)、ゼロ件 exit 1、JSON 出力の構造。実在 task_id(例 P8-T01)での実行ログを検証ログに含める(スモーク)。
4. **`docs/OPERATIONS.md` 追記(1 節)** — 監査突合手順: `npm run audit:trace -- <task_id>`、出力の読み方、一次台帳は基盤 JSONL である旨(問題 17 の運用面)。

- 未コミットの既存 dirty ファイルに触れない・ステージしない(artifacts/\*.jsonl が dirty だが読み取りのみ)。
- Commit prefix `P8-T06:`、author mryfmo <mryfmo@gmail.com>、署名分離フラグ従来どおり。
