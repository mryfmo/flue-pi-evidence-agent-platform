## 4. Background / fixed decisions

- Current instructions live inline in `src/agents/remediator.ts` ("You are an evidence-driven remediation agent. Summarize only verified facts.").
- **Decision 1 — skill registry layout** (files, no new infra):
  - `.orchestration/skills/promoted/remediator/best_skill.md` — v1 = EXACT current instructions, YAML frontmatter: name, version 1.0.0, provenance (baseline import), validation evidence pointer, rollback: none.
  - `.orchestration/skills/candidates/remediator/candidate_skill.md` — ONE proposed improvement authored by you (v1.1.0-candidate): keep the summarization-only constraint; add concrete guidance (reference hypothesis IDs, list evidence kinds, state verification outcomes; never claim unverified facts). Frontmatter: provenance (source: SkillOpt cycle 1; informed-by: AutoSkill candidates list), promotion_allowed=false.
  - `.orchestration/skills/rejected/remediator/` — rejection buffer (record format documented; empty initially).
- **Decision 2 — product hook (minimal)**: `src/agents/remediator.ts` reads instructions from the file at `EAP_REMEDIATOR_SKILL` env (markdown body without frontmatter) when set; default = current inline text. Fail closed on unreadable file (error, not silent default).
- **Decision 3 — cycle harness** `scripts/skill-cycle.mjs`:
  - runs held-out evaluation (`npm run flue:e2e:heldout` from P4-T02) once with best and once with candidate (EAP_REMEDIATOR_SKILL);
  - pass criteria per run: workflow exit 0 + closure achieved + e2e artifact assertions;
  - verdict: candidate `validated` only if its run passes AND full `npm run validate-release` stays green; writes `.orchestration/skills/candidates/remediator/cycle-<n>.verdict.json` (runs, criteria, outcome);
  - honest limitation note printed + documented: with the deterministic local gateway the cycle validates NON-REGRESSION of the gated pipeline; semantic quality comparison activates when the production gateway path is used for summarization (future note, do not implement).
- **Decision 4 — docs**: `docs/SKILL_OPTIMIZATION.md`: registry layout, state transitions (candidate→validated→promoted / rejected), promotion authority (orchestrator acceptance only), rollback (git revert of best_skill.md + provenance chain), rejected-buffer anti-resubmission rule.
- `.agents/worklog/**` allowed.
