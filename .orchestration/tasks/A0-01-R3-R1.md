The failure path sends default SIGTERM once and settles only on `close`. A
child that ignores SIGTERM therefore leaves the Promise and process alive
indefinitely.

Required outcome:

  residual child. Preserve `classification_unavailable`.

  alive. An outer bounded oracle must prove classification rejects finitely,
  the child reaches `close`, and no timer/process keeps the test alive.
- Retain EPIPE, nonzero, malformed, canonical/digest/shape, stdout/stderr
  overflow, and ordinary timeout coverage.
