# Task P2-T08: Deploy smoke test (single-host container service smoke)

## 1. Role

You are Codex CLI, model gpt-5.5, reasoning effort high, standing agmsg worker codex-gpt55-high. Worker, not orchestrator. Perform only this task.

## 2. Objective

Implement the §14-3 "デプロイスモークテスト" gate. Definition (fixed): for this single-host platform, the deployable artifact is the validated container image; deploy smoke proves the image runs as a service — (a) the Flue/Pi smoke workflow (`flue:smoke`, deterministic local gateway ack path) exits 0 inside the container, and (b) the built app server starts inside the container and answers `/health` with HTTP 200.

## 3. Defensive engineering scope

Release/deployment verification. No offensive content.

## 4. Background / fixed decisions

- Reuse the existing validation image (`Dockerfile`, tag flue-pi-eap:validate) — no second image. Smoke = running that image with command overrides.
- New script `scripts/deploy-smoke.sh` (shdoc headers, runtime-agnostic docker→container fallback like scripts/container-validate.sh):
  1. Build (or reuse) the image.
  2. Check A: `run --rm <image> npm run flue:smoke` → exit 0 and stdout contains the deterministic ack marker (read src/workflows/smoke.ts for the exact expected output; assert on it).
  3. Check B: run the image with the app server started (inspect package.json / src/app.ts / flue build output for the correct start command; document it), poll `/health` until 200 (timeout 60s) — polling can run inside the container via a shell loop with the app backgrounded if port-mapping across runtimes is awkward; choose the simplest approach that works for BOTH docker and Apple container, and record the choice.
  4. Exit non-zero if either check fails; print a one-line PASS summary.
- CI: add a "Deploy smoke" STEP to the existing `container-validate` job (after the gate run; reuses docker layer cache) — not a new job.
- Docs: DEPLOYMENT.md "Deploy smoke" section (what it proves, how to run locally); RUNBOOK.md one entry; VALIDATION_PLAN.md CI-only gates subsection gains the row.
