## 7. Implementation instructions

1. `productionGateway.ts`: `callProductionGateway(request)` implementing the design's request/response contracts:
   - preflight order: load+validate routing config -> selectRoute -> redactText (fail closed if redaction errors) -> authorizeRoute via eap.routing (fail closed) -> resolve provider env vars (missing -> fail closed, no dispatch);
   - dispatch: POST `{base_url}/chat/completions` (openai-completions shape, non-streaming is sufficient);
   - fallback chain walk on provider error/timeout; `local` provider entries use mode `deterministic-fallback` and must be marked in audit;
   - audit event via appendAudit: audit_id, trace_id, provider, model_id, route_id, routing_policy_version, fallback_index, latency_ms, token usage, estimated_cost, sha256 digests of redacted request/response — NEVER raw prompt/response text, NEVER key material;
   - telemetry span with the design's `gateway.*` attributes;
   - all-fallbacks-failed -> typed failure result (no fabricated summary).
2. `data_guard.py` `redact_text`: read JSON {"text": ...} on argv/stdin consistent with existing command style, return {"redacted_text": ..., "entities_found": n}. Deterministic, offline.
3. Contract tests (`tests/contract/llm_contract.test.ts`), using a minimal mock openai-compatible server (reuse/adapt the localGateway harness):
   - happy path returns content + response contract fields;
   - redaction: seed input with a deterministic PII example (email) and assert the mock-received body does not contain it;
   - audit: assert JSONL record has required fields and no raw content;
   - fail-closed: missing api key env / OPA deny (tenant mismatch) / missing routing config -> mock receives ZERO requests;
   - fallback: first provider URL unreachable -> second (mock) serves the call and fallback_index recorded.
4. `validate-release.mjs`: add gate `llm_contract` running `npx vitest run tests/contract --pool=forks` positioned after `vitest_all`.
5. Docs: append the 6 REQ entries (SPECIFICATION.md) and traceability rows (TRACEABILITY.md) exactly in the style of existing entries; spec-check must stay green.
