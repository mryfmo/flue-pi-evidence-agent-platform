- **Decision 1 — shim** `.orchestration/autoskill/config/codex_auth_proxy.mjs` (node stdlib only, no deps):
  - POST `/v1/chat/completions` (non-streaming) with `Authorization: Bearer $EAP_SHIM_TOKEN` (401 otherwise; token supplied via env at launch, never logged);
  - maps messages → a single prompt; runs `codex exec --sandbox read-only --cd <empty scratch dir> --skip-git-repo-check -m gpt-5.5 -o <tmpfile> "<prompt>"` and returns the final message as an OpenAI-shaped response (choices[0].message.content; usage zeros are acceptable);

  - mode openai: requires `AUTOSKILL_LLM_BASE_URL` + `OPENAI_API_KEY` envs; mode codex: requires `EAP_SHIM_URL` + `EAP_SHIM_TOKEN` (points AutoSkill's openai provider at the shim with the token as api key);

  - writes `.orchestration/autoskill/runs/<run-id>.autoskill.md` (pinned SHA, provider mode, decision counts, generated candidates list, redaction_passed=true reference, promotion_allowed=false).
