# P2-T01 Sandbox

## Environment

- Codex workspace-write fallback.
- OpenSandbox unavailable.
- Host observed by Node: `darwin arm64`.

## Network Escalations

| Command | Destination | Purpose | Residual risk |
| --- | --- | --- | --- |
| `npm install --no-audit --no-fund` | `registry.npmjs.org` | Regenerate `package-lock.json` and install the darwin-arm64 optional OPA package. | Package integrity is pinned in `package-lock.json`; registry availability remains an install-time dependency. |
| `npm ci --no-audit --no-fund` | `registry.npmjs.org` | Verify clean install with optional platform dependencies and no `--force`. | Same registry/integrity risk as normal clean installs. |
| `env -u EAP_OPA_BINARY npm run validate-release` | localhost and npm registry endpoints used by existing gates | Run localhost-bound tests and npm audit/SBOM gates outside sandbox. | Networked audit/SBOM results can change with registry advisory state. |

## Notes

- Generated validation artifacts and demo workspaces were restored/removed after verification because they are outside the P2-T01 allowed file list.
