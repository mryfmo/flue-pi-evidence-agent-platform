## Learnings

- `@alibaba-group/opensandbox@0.1.9` exposes `ConnectionConfig`, `Sandbox.create`, `sandbox.files`, and `sandbox.commands.run`, which are sufficient for the existing `SandboxExecutor` contract.
- The SDK accepts full pinned image references in `name:tag@sha256:digest` form through `Sandbox.create({ image })`.
- `ConnectionConfigOptions` uses exact optional properties, so optional values such as `apiKey` must be omitted instead of set to `undefined`.
- OpenSandbox command execution returns accumulated `logs.stdout`, `logs.stderr`, optional `error`, and optional `exitCode`.
- Local validation can keep deterministic behavior by skipping OpenSandbox integration unless `EAP_OPENSANDBOX_URL` is configured.
