## Learnings

- The Flue Node server starts with `PORT=3000 ./node_modules/node/bin/node dist/server.mjs` and logs `[flue] Server listening on http://localhost:3000`.
- `src/app.ts` exposes `GET /health` and returns JSON `{ ok: true }`.
- The deterministic smoke marker is `ack:hello`, derived from `src/workflows/smoke.ts` and the `flue:smoke` payload.
