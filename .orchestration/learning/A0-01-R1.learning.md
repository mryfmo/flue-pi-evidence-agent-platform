# A0-01-R1 Learning Triage

## Learning

OPA `object.union` recursively preserves nested members. A negative test that replaces a nested object with a smaller object can accidentally retain the supposedly missing field. Remove the parent field first, then union the replacement when constructing missing-field adversarial inputs.

## Validation

This was reproduced by the initial missing-proof test and corrected with `object.remove(valid_decision, {"classification"})` before inserting the proof-less classification. The corrected OPA suite passes 38/38.

## Disposition

Reusable and validated, but not promoted by this worker. The orchestrator may consider it as a future Rego testing rule candidate.
