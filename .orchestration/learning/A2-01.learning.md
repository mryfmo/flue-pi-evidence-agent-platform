# A2-01 learning

File-byte integrity and tuple integrity are separate controls. EOF normalization can legitimately change the frozen JSON file digest while leaving the canonical tuple digest identical; an approved repair should update only the file-digest chain and verify both tuple digests remain fixed.

Structural CLI fixtures must not bootstrap themselves from repository validation artifacts. A real full run is allowed to delete those artifacts before regenerating them. Structural fixtures should copy only existing source/test/gate files, while filename-only and canonical post-run fixtures must generate their own deliberately untrusted or fully bound evidence sets.
