# P3-T03 Learning

## Reusable Learning
- Presidio built-in recognizers for email, phone, credit card, IP address, and URL can be used directly without NLP model downloads.
- `CreditCardRecognizer` applies Luhn validation, which is useful for guarding order-number false positives.
- Mypy needs an explicit `Any` cast at the `nlp_artifacts=None` call boundary when iterating over the base recognizer type.
