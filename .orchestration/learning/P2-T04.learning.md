## Learnings

- `pip-audit --dry-run --format cyclonedx-json` does not produce a useful component SBOM for this environment.
- `pip-audit 2.10.1` does not support severity filtering in its CLI help, so fail-on-any-finding is the practical audit behavior.
- `cryptography>=48.0.1` is required as a transitive security floor for `presidio-anonymizer`; after reprovisioning this host installed `cryptography 49.0.0` and `pip-audit` passed.
- `setuptools>=78.1.1` is required as a venv-seeded security floor for Debian Bookworm/container Python environments affected by `CVE-2024-6345` / `PYSEC-2025-49`; this host has `setuptools 79.0.1` after reprovisioning.
