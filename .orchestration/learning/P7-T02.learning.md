# P7-T02 Learning

## Reusable Findings

- CLI parsers must preserve empty string option values; treating `""` as "no value" can turn a required argument into a boolean flag and bypass validation.
- Registry lifecycle evidence should fail closed. Requiring report, validation, and acceptance inputs is simpler and safer than carrying partial-evidence semantics.
- Expected-failure tests for child-process CLIs are useful but can produce noisy TAP diagnostics; keep the assertions narrow and the scenarios few.

## Apply To

- Future orchestration lifecycle scripts that write under task-derived paths.
- Future release-gate additions: add focused checks as named `validate-release` commands so final reports prove they ran.
