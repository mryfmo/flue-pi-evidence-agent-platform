# P7-T01 Learning

## Reusable Findings

- For native skill lifecycle automation, filename-based skill detection must use `basename(file)`, not the full path. Every registry path contains `.orchestration/skills`, so full-path matching makes worksheets such as `p2t07b.triage.md` look like skill files.
- The safest way to demo lifecycle output on historical task evidence while respecting a narrow allowed-files list is to copy the historical evidence into a temporary fixture and run the scripts there.

## Apply To

- Future registry scanners and activation loaders should mirror `scripts/check-skill-registry.mjs` and decide skill-ness from the filename.
- Future orchestration tasks with conflicting acceptance/demo output paths should record demo evidence in validation logs instead of leaving disallowed generated files in the working tree.
