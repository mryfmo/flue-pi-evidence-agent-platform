# P8-T04 Learning

## Reusable observations

- `validate-release` should be run outside the main dirty worktree when broad
  generated artifacts are already dirty; a temp clone keeps staging clean.
- For this repo, temp-clone `validate-release` needs a real copied
  `node_modules`; symlinking `node_modules` causes `npm sbom` to report missing
  transitive packages.
- The Flue e2e gate binds `127.0.0.1`, so sandboxed runs can fail with
  `listen EPERM`; escalation is required for that validation path.
