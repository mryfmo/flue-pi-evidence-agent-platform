# P3-T04 Learning

## Learned
- SQLGlot AST traversal can enforce metric-query policy without matching a fixed query string.
- A global `Column` scan is a simple way to deny PII references across projection, WHERE, GROUP BY, HAVING, ORDER BY, CTEs, and subqueries.
- Projection validation is clearer when separated from whole-query checks: one helper owns table/set/PII policy, another owns grouped-column and aggregate-only projection policy.

## Applied
- Reflected in `scripts/data_guard.py` via `validate_metric_sql` and `validate_select_projection`.
- Reflected in `tests_py/test_data_guard.py` with accept/reject cases for the structural rules.
- Reflected in `docs/DATA_GOVERNANCE.md` with the SQL validation rule table.
