# P8-T08 Learning

## What Changed Decision-Making

- `sqlite3 <missing-db> SELECT 1` is not a health check for agmsg because sqlite3 can create an empty DB and return success. Health checks must assert the expected schema/table, here `messages`.
- Bash guard extraction must not limit itself to known controlled prefixes. Extract plausible path tokens first, normalize them, then let OPA/builtin policy decide whether they are controlled or leased.
- On macOS, temp paths may appear as `/var/...` in generated commands while the spawned process resolves cwd as `/private/var/...`; absolute path normalization needs to account for that alias to avoid missing controlled workspace paths.
- LiteLLM config declarations are not sufficient runtime bind enforcement; production runbooks must include explicit CLI bind flags.

## Where To Apply

- Future orchestrator health checks should validate real schema/contracts, not generic process reachability.
- Future pretool hooks should keep extraction broad and denial policy narrow.
- Future docs for runtime security controls should distinguish repository validation declarations from actual runtime enforcement.
