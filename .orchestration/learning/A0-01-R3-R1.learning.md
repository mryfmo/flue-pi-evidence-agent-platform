# A0-01-R3-R1 Learning Triage

## Reusable findings

- A shared development interpreter override must not be reused by a security producer that mints authorization evidence. Fix the production command at a deployment-owned absolute path and keep arbitrary-command seams incapable of entering the verifier's authenticity set.
- A timeout that waits for `close` is finite only when its termination signal is non-ignorable or escalation is independently bounded. Security subprocess tests need a SIGTERM-ignoring fixture plus a post-close PID oracle.
- Bundle-relative `import.meta.url` paths can drift when source modules are flattened. When deployment already owns a stable working directory, resolve it once and use absolute child argv.

## Disposition

Useful as future task/test guidance, but no rule or skill promotion was requested or performed. The findings are recorded only in this task evidence.
