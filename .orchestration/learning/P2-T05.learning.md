# P2-T05 Learning

## Summary

The platform remains zero-secret for deterministic validation. Live provider credentials are needed only when production routes are enabled, and current routing policy references environment variable names rather than credential values.

## Reusable Learnings

- Keep `.env.example` to names, comments, and empty values only; use `grep -E '=..+' .env.example` as a quick check for populated assignments.
- Inventory must track every env var referenced by `policy/routing.json`: `ANTHROPIC_API_KEY`, `OPENAI_API_KEY`, `VLLM_BASE_URL`, and `VLLM_API_KEY`.
- Managed secret-store adoption should wait until the first of multi-host deployment, multiple credential operators, compliance requirements, or unreliable manual rotation.

No persistent plan update is required for this docs-only task.
