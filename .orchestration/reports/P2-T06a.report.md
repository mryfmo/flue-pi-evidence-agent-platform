## Design Summary

The design makes OpenSandbox the product-required isolation layer for remediation workspace operations while keeping the current local workspace behavior as the default deterministic validation path.

Key decisions represented:

- Coexistence via `SandboxExecutor`, `LocalWorkspaceExecutor`, and `OpenSandboxExecutor`.
- Explicit `EAP_SANDBOX_RUNTIME=local|opensandbox`, default `local`.
- No silent fallback when `opensandbox` is selected.
- Typed create/putFiles/exec/collectArtifacts/destroy contract with audit and trace IDs.
- Credential isolation, default-deny egress, artifact caps, lifecycle audit, and OPA `eap.sandbox` policy boundary.
- Exact version pinning for SDK, server image, and sandbox image.
- CI-only OpenSandbox integration job on ubuntu runners with Docker.
- T06b/T06c migration split.
