Added a versioned remediator skill registry, file-backed instruction hook, deterministic skill-cycle harness, and SkillOpt documentation. The implementation keeps promotion authority outside the worker and performs no LLM calls or gateway rewiring.

## Candidate Skill Rationale

The candidate keeps the original summarization-only constraint and adds concrete output guidance: reference hypothesis IDs, list evidence kinds, state verification outcomes, report remaining hypotheses, and never claim unverified facts. This is a non-regression candidate for the deterministic gateway path; semantic comparison is deferred to the production gateway path.
