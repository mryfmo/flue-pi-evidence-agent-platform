# P7-T02 Report

## Summary

Hardened the native skill lifecycle flow from P7-T01 against the four Round 3 findings:

- V3-1: task ids now pass through `safeTaskId()` in `observe`, `decide`, and `apply`.
- V3-2: `observe` now requires evidence from all three groups: `reports`, `validation`, and `acceptance`. `decide` and `apply` require a non-empty manifest and validate each `redacted_path` exists under `.orchestration/autoskill/inputs/<task>/`.
- V3-3: `validate-release` now includes a `skill_lifecycle_node` gate that runs `node --test tests/unit/skill_lifecycle.test.mjs`.
- V3-4: `apply --decision create` rejects an existing candidate unless `--overwrite` is passed, and TRIAGE duplicate lifecycle sections are rejected instead of appended again.

## Evidence Choice

For V3-2 I chose the strict option: `observe` requires at least one matching file from each of `reports/`, `validation/`, and `acceptance/`. The lifecycle is a registry/evidence gate, so silently accepting partial evidence would recreate the same provenance ambiguity.

## Failing-First Coverage

The new unit tests encode the old failure modes:

- `../x`, `x/y`, empty, and overlong task ids fail before artifact writes.
- Missing and partial evidence fail during `observe`.
- Missing, empty, and path-escaping manifests fail during `decide` / `apply`.
- Duplicate candidate and duplicate TRIAGE lifecycle sections fail during `apply`.

One targeted run exposed an additional parser edge where `--task ""` became boolean `true`; that was fixed by preserving empty string option values so `required()` rejects them cleanly.

## Validation

- `npm run test:skill-lifecycle` passed.
- `npm run validate-release` passed.
- `artifacts/validation/final_verification_report.md` includes `skill_lifecycle_node: passed`, proving the release gate now runs the lifecycle Node tests.

## Constraints

- No Hermes runtime added.
- No LLM or network calls added to the lifecycle implementation.
- `promotion_allowed=false` behavior remains unchanged.
- Release gates were strengthened, not weakened.
