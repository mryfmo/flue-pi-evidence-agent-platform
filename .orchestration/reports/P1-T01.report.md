## Design Summary

The new design keeps `src/lib/localGateway.ts` as the deterministic validation provider and adds a production gateway as a separate Pi provider behind the same `openai-completions` contract.

It specifies deterministic policy routing over tenant, data classification, task kind, cost budget, and latency target; OPA authorization through `eap.routing`; outbound redaction before external calls; audit and OpenTelemetry propagation; provider fallback; mock-provider contract testing; and a P1-T03 minimal implementation scope.
