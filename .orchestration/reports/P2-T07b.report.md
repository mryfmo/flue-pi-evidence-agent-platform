## Shim Security Notes
- Requires `EAP_SHIM_TOKEN` and `PORT` at startup; exits closed when missing.
- Accepts only `Authorization: Bearer $EAP_SHIM_TOKEN` for `POST /v1/chat/completions`; wrong or missing bearer returns `401`.
- Supports `GET /healthz` without content.
- Does not log prompt or response content; writes only request count and latency to `.orchestration/autoskill/runs/shim.log`.
- Runs `codex exec` with `--sandbox read-only`, `--skip-git-repo-check`, and an empty temp scratch cwd.
- Sends prompt through stdin instead of a shell command string, so prompt text is not put in the wrapper command line.
- Sequentializes requests with a simple promise queue and applies a 180s timeout.

## Acceptance Launch Commands
Start the shim on the host:

```bash
export EAP_SHIM_TOKEN="<acceptance-only random token>"
PORT=8787 node .orchestration/autoskill/config/codex_auth_proxy.mjs
```

Run the Codex Auth dry-run from Docker:

```bash
EAP_SHIM_URL="http://host.docker.internal:8787/v1" \
EAP_SHIM_TOKEN="$EAP_SHIM_TOKEN" \
.orchestration/autoskill/config/run_autoskill.sh --auth codex --run-id p2t07b-acceptance
```

Run the Codex Auth dry-run from Apple `container` with an explicit host override:

```bash
EAP_SHIM_HOST="<container-vm-gateway-ip>" \
EAP_SHIM_PORT=8787 \
EAP_SHIM_TOKEN="$EAP_SHIM_TOKEN" \
CONTAINER_RUNTIME=container \
.orchestration/autoskill/config/run_autoskill.sh --auth codex --run-id p2t07b-acceptance
```

Run the direct OpenAI-compatible mode:

```bash

.orchestration/autoskill/config/run_autoskill.sh --auth openai --run-id p2t07b-openai
```
