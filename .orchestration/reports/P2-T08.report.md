- Health assertion: `src/app.ts` registers `GET /health`; the script polls `http://127.0.0.1:3000/health` for HTTP 200 from inside the container. In-container polling avoids Docker vs Apple container host port mapping differences.
- Build choice: the health check runs `npm run flue:build` inside the image before starting the server because `.dockerignore` excludes `dist/`.
